# Simulador Bancario en C#

Proyecto desarrollado para la materia Estructura de Datos.

Este sistema implementa un simulador bancario en consola utilizando estructuras de datos desarrolladas manualmente en C#.

---

 Funcionalidades

- Registro de clientes
- Búsqueda y listado de clientes
- Gestión de cola de atención bancaria
- Depósitos y retiros
- Consulta de saldo
- Deshacer transacciones
- Total de clientes registrados
- Total de dinero almacenado en el banco

---

 Estructuras de datos utilizadas

 Lista Enlazada
Utilizada para almacenar y recorrer los clientes registrados.

 Cola
Utilizada para gestionar el orden de atención de clientes.

 Pila
Utilizada para guardar el historial de transacciones y permitir deshacer operaciones.

---

 Tecnologías utilizadas

- C#
- .NET
- Visual Studio Code
- Git y GitHub
